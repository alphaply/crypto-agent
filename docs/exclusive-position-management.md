# 可见仓位与挂单管理

Agent 与 MCP 默认管理授权账户和标的内可见的仓位、挂单及现货余额。后台发现真实资源，或有效交易请求首次触达目标时，会原子登记管理者；先成功登记者持续拥有该范围。启动前已有资源、运行期间的外部操作均可在核验后管理，不要求模型先调用接管工具。

## 开启入口

- 内部 Agent：管理页 → 任务与调度 → 编辑任务 → 基础设置 → 仓位与挂单管理。
- MCP：管理页 → MCP → 交易连接配置 → 编辑 → 仓位与挂单管理。

默认选择「自动管理可见资源」。REAL 的关联保护与独立退出、SPOT_DCA 和 MCP 交易配置均适用。选择标的包含 LONG/SHORT 的管理资格，但空的双向方向不会预先占用；单向账户的实际范围为 BOTH。兼容导入可明确保留旧「仅原有归属」或「独占指定范围」策略。

保存配置、查询账户和发现工具本身不会登记管理权。后台纳管与金融请求会检查当前 owner；同范围有其他管理者时显示冲突，其他未冲突范围仍可工作。迁移保留有效既有 owner，已完成周期和账户暂时清零不会释放管理权。

MCP 的「不限制标的」按实际可见资源或有效请求目标逐个登记，不使用预设 30 个标的，也不预占整个市场。交易、撤单权限以及绑定任务聊天的审批继续生效；只读调用不会登记管理权。

相同 API Key 的别名自动共享账户身份。不同 API Key 确实属于同一账户时，使用保存账户的相同物理账户 ID；系统不根据密钥相似性猜测。同一账户 ETH/USDT 与 ETH/USDC 的现货管理共享 ETH 基础资产范围。

## 人工操作后如何继续管理

例如 ETH 多仓 0.02，人工挂有 TP 2565、SL 2458 和限价入场 2385。开启对应账户、ETH 合约和 LONG 独占范围后，后台读取交易所事实、记录接管基线并纳入可支持的挂单。基线代表观察到的现有数量，不会生成虚假的入场成交或历史收益。

Agent 与 MCP 使用 `execute_trade_actions` 提交有序动作；例如先 cancel，得到已完成确认后再 open。每个动作执行前重新核验最新资源；已提交的订单不等于已成交，未确认撤单不会释放容量。真实提交结果尚未确认时，后台保留原身份继续查询，避免重复交易。

| 人工动作 | 系统与 Agent 的行为 |
| --- | --- |
| 加仓、减仓 | 后台补齐成交和当前数量；Agent 按最新仓位管理。 |
| 修改挂单价格或数量 | 更新原订单的真实参数；只改价格时保留最新数量，不恢复人工修改前的值。 |
| 新增挂单 | 核验方向、作用与类型后登记；支持的订单可以使用原 edit/cancel 工具。 |
| 撤单 | 更新原单状态，不自动恢复旧挂单。 |
| 全平或平仓后重开 | 后台核验成交边界和残单；保留平仓事实与新仓位，不将旧全平单当作新仓位的有效保护。 |
| 查询不完整 | 显示尚未完整核验及受影响动作，不把失败表示为空仓或无挂单。 |

自动纳管不会自动撤销人工挂单。固定退出数量也不会随着人工加减仓自动按比例调整。多个固定退出单合计超过当前仓位时，界面显示数量冲突，Agent 可提出有效的修改或撤销。

保护覆盖是当前挂单的估计，不保证成交。条件限价单触发后仍需成交；支持的动态「全部」条件单按交易所实际规则覆盖触发时的仓位。原生组合或方向无法核验时，系统会保留能力限制，不猜测订单语义。

## 查看当前状态

Agent 的行情与账户视图显示管理者、管理范围、来源和最近核验时间。仓位数量来自交易所当前读取；接管基线、历史周期和账本不替代当前仓位。

来源分为 Agent、外部和接管基线。无法证实操作者时，不把「外部」写成「人工」。挂单显示普通/条件渠道的订单身份、来源、纳管状态、支持动作及观察时间；同数字的普通单与条件单保持不同身份。

「支持动作」描述适配器能力，执行时仍会重新检查权限、数量和必要证据。已纳管不等于每个动作已经获准。部分订单通道读取失败时，页面只展示已取得的订单，并明确不能确认没有其他挂单。

暂停、禁用、重启、完整平仓及 MCP token 到期仍保留 owner。删除、缩小范围或更换账户前，在管理面板明确释放或转交。释放需要确认没有仓位、挂单及未决操作；接收者明确接受的原子转交可带上有稳定身份的未决资源。运行中的原 worker 会阻止交接；交接后旧 worker 不能继续金融写入。接收者只获得这些资源的受限查询恢复身份，不能访问来源任务的其他回执，也不能重提未知操作。

现货可管理数量来自真实基础资产余额，基线与历史 Agent 成交分别显示。可卖数量同时受 free 余额、管理数量和不同订单预留限制；原生 OCO 的互斥两腿只预留一次。历史费用缺失只标记历史归属待核验，不把基线伪造为 Agent 入场或收益。

现货买单改单会先核验新增计价币承诺、共同运行额度和任务总预算；外部买单也受当前任务额度约束。改单返回 ACK 后还要按原目标核验提交前保存的总量与价格，迟到成交不改变原预期总量。明确拒绝仅释放本次新增额度，原挂单仍计入承诺。普通卖单与 OCO 撤销后缺少终态成交证据时，保留本资产预留，即使交易所已释放 free 余额也不能提前卖出。原生条件单没有普通子单或基础币余额已清零时，仍需查明其终态才能释放 owner。

## 记忆与收益

短期记忆正文只保留策略判断、关键价位和有效教训，例如等待四小时收盘或 CPI 后反应、关注 2385/2565、亏损后不加杠杆。当前仓位与挂单来自最新交易状态。周期报错、操作身份、恢复步骤和账本 JSON 不再进入默认策略正文。

已认证用户可以展开「历史原文与审计详情」查看原始记忆及历史证据。该原文不是当前持仓，也不会自动进入新记忆。

收益与回撤默认只展示：

- 权益变化：本地权益快照的起点、终点、变化及收益率，非实时余额；账户转账和其他策略可能影响它。
- 已实现盈亏：REAL 使用已归属成交及可核验费用，STRATEGY 使用模拟已实现盈亏；数据不足时显示「暂不可统计」。
- 回撤：所选区间内快照的当前回撤和最大回撤，可能漏掉盘中极值。

支持最近 1、7、30 天区间。「查看账本详情」按需读取成交、手续费、归属、周期、同步范围和完整历史证据。完整周期盈亏与按成交时间统计的盈亏不可相加；详情不会自动写入策略记忆。原始账本和回执继续保留供审计。
