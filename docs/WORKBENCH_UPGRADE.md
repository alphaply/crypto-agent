# 工作台改造与验证记录

日期：2026-09-19

## 体验改造

桌面聊天采用有界阅读区、独立会话搜索和请求时间线；移动端处理视口高度、安全区、换行输入、抽屉与可滚动创建表单。临时聊天自动复用已保存的账户和模型，提供默认研究要求，将模型兼容性放入高级选项。创建失败显示在弹窗内，必填缺失时不可提交。

请求时间线记录实际收到的状态、推理摘要、回答生成、工具调用、审批及结束事件，同时显示耗时和输出字符数。没有上游推理内容时不生成虚构思考。完成、停止、失败有独立文字状态。

Prompt 可搜索、专注编辑、快捷保存；保存结果与未保存状态明确区分。草稿暂存在当前标签页的 sessionStorage，离开配置页面再返回可恢复。文件切换可选择取消丢弃。保存按钮位于顶部，不必滚动到编辑区底部。

## 数据准确性

- RSI/ATR/ADX 使用 SMA 初始化的 Wilder 递推，避免短样本中的初始化偏差。RSI 不再将预热期伪装成有效数值；完全横盘时按 50 处理。
- OHLCV 检查非有限值、负成交量、非正价格和不合法高低价，剔除异常记录。时间缺口、失效数据、预热不足会进入模型上下文提示。
- 成交量倍数相对于之前 20 根已收盘 K 线计算，排除当前柱对基准的自我稀释；基准缺失为不可用。
- 权益曲线默认使用直线连接实测快照，避免平滑插值造成视觉过冲。

公式参考：[TradingView RSI](https://www.tradingview.com/support/solutions/43000502338-relative-strength-index-rsi/)、[TradingView ATR](https://www.tradingview.com/support/solutions/43000501823-average-true-range-atr/)。

线上公开页面检查时显示胜率 35%；这不是归因分析，不能据此证明某个指标导致亏损。本次未改变实盘账户风险参数，也未执行实盘交易。后续仍需按完整持仓周期、手续费后收益、样本数、盈亏比和回撤评估效果。

## 下载与维护

导出保持原有带 Bearer 鉴权接口兼容，使用 FileResponse 传输临时 SQLite 在线备份文件。新 UI 先申请短时、HttpOnly、同站点、仅下载路径可用的凭据，再交给浏览器下载；不把管理员 JWT 放到 URL。备份包含 WAL 中已提交数据。快照准备并非零延迟，数据库持续高写入时会超时而非无限等待。

清理提供 7/30/90 天保留策略、遗留任务列表和条数预览。全局表不能套用任务过滤；成交、订单关联和持仓保护证据不在快捷清理范围内。预览指纹分批计算，避免把海量 rowid 一次读入内存。不会自动清理用户生产数据。

## 修复与验证

修复了会话切换与流式响应交叉更新、过滤消息后的流式标记索引、重复发送窗口、SSE CRLF/多行事件处理及 reader 释放、Prompt 文件路径校验、静态文件路径边界和 API 错误对象丢失状态等问题。

本次整合保留了工作区原有交易重试、模型回退、保护单、持仓历史统计及配置改动；通过完整后端回归验证兼容性。

验证方式：

- `uv run pytest -q`：完整后端回归（含新增 Wilder 边界、WAL 快照、下载鉴权与过期、Prompt 路径限制测试）。
- `npm run build --prefix frontend`、`npm run lint --prefix frontend`、`npm run test:chat --prefix frontend`。
- 真实浏览器读取线上公开看板；本地隔离 SQLite、关闭调度器，使用明确标注的模拟聊天事件验证桌面与 390px 手机布局、创建临时会话、阶段可视化、Prompt 快捷保存/专注编辑及清理预览。未向实际模型发出测试交易指令。
- ECharts 按需注册后相关资源由约 1,141 kB 降至 548 kB（gzip 374 kB → 185 kB）；仍有 React/Ant Design 大包构建提醒，不影响构建通过。

镜像发布目标：`alphaply712/crypto-agent:latest`。推送镜像不会自动替换线上正在运行的容器。

验证结果：346 项后端测试通过（另有 16 个 subtests），17 项前端测试通过；生产构建、ESLint 与 `git diff --check` 通过。现有模型连接测试有一个返回值风格警告。对本地 218.79 MiB 数据库的一致性快照实测约 0.728 秒（仅本机磁盘准备耗时，不代表公网下载速度）。

发布前依赖审计发现 15 项已知问题，已通过兼容版本更新锁定依赖；官方 npm registry 审计结果为 0 vulnerabilities。更新后的构建、lint 和 17 项前端测试重新通过，并补充 RSI/ADX 手算参考值回归测试。
