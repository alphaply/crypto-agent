# Dashboard 调度与界面修复

## 显示规则

- 下一次运行使用与调度器相同的 `run_schedule`，按规则时区、星期、起止时间、第一条匹配优先级和时段起点计算；非匹配时段使用默认间隔。
- 页面同时展示完整月日时间、调度时区、当前有效频率及可展开的规则。暂停调度时不显示未来执行承诺。计划时间不是执行完成时间，排队可能延迟实际启动。
- DCA 使用日/周配置和已执行状态，兼容周频别名，并保留目标时间后当日补执行的语义；跨年去重按 ISO 周年处理。同进程可读取调度器去重状态；分离部署时，以数据库已有订单及计划规则估算。

## 界面与刷新

- Dashboard 只显示总览指标、收益、任务数据列表与共享消息；独立的 `/agents`（管理入口 `/console/agents`）承载任务选择、运行状态、K 线、持仓、决策、摘要和记忆。总览中的查看入口跳转对应任务；旧任务深链保持兼容。两个页面均支持移动端和深浅主题。
- Agents 只有一个任务时不展示目录、搜索和筛选；多任务保留目录，手机横向切换。任务名称、模型、状态、最近运行和下次计划集中在顶部，调度规则按需展开。
- 工作区默认「运行过程」，顺序展示决策模型原文与工具调用、纯文本策略摘要、短期记忆及更新状态。另设「行情与账户」「交易记录」。运行中及失败提示始终可见，交易记录按需加载。无委托时显示简短空态；桌面委托表仅展示有数据的触发价和 TP/SL 列，原因与订单号可展开查看。
- 确认无持仓、无退出单且多空未覆盖数量均为零时，省略空退出表格；未知覆盖、待核验和错误状态继续展示。
- 累计指标明确统计口径，无成交时胜率显示未知。持仓/行情失败会显示警告并保留已有数据，不把加载失败伪装成空仓。
- 看板每 8 秒更新完整快照；只有 Agents 页加载当前任务的工作区，行情和权益约每 32 秒刷新，新分析完成也会刷新行情。后台标签页暂停自动请求，后台快照刷新不闪烁全局加载条。
- 请求设定超时，切换与卸载会取消相关请求；推理文本更新不再触发全部行情重载。工作区接口只读取目标配置，避免重复构建整个交易对总览。
- 修复订单页数越界以及总结/记忆在切换交易对时保留旧筛选和迟到响应覆盖的问题。

## 验证

`uv run python -m pytest tests -q`；`npm run lint --prefix frontend`；`npm run test:dashboard --prefix frontend`；`npm run test:chat --prefix frontend`；`npm run build --prefix frontend`。

调度回归覆盖时段切换、跨日、暂停、DCA 补执行与 ISO 跨年周。浏览器使用隔离 SQLite 与模拟行情检查 390px 手机和 1440px 桌面、深浅主题、规则展开、交易对切换及失败提示；线上页面仅用于读取现状。
