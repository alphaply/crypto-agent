# 持仓历史与现货任务统计

任务工作台保留任务概览、决策与操作、策略与记忆、历史记录四个入口。登录后的历史记录默认展示持仓历史，操作记录和订单记录分别保留。桌面使用明细表，手机使用纵向卡片；刷新保留上次结果，并显示更新失败原因。

## 持仓历史

实盘合约、模拟合约、现货均按当前任务、账户、标的及方向展示本地保存的证据。从实际建仓到持仓归零为一轮，部分成交、加仓、减仓属于同一轮；归零后再次建仓产生新记录。进行中和已结束的记录保持同一编号。默认进行中优先，其余按最后变化倒序，每页 20 条，可筛选标的和状态。

列表提供开始、结束和持续时间、累计建仓量、剩余量、费前盈亏、原币种费用及净盈亏。展开后逐笔展示变化、成交价格、变化前后数量、原始订单/成交编号和已保存理由。现货成本校准单独标记，不是买入、利润或成交次数。

净盈亏包含实际交易手续费和返佣，不包含合约资金费。实盘合约按成交记录的已实现盈亏扣除本轮开平仓费用。现货买入手续费计入成本，随实际卖出数量结算；完全退出后包含本轮全部买卖费用。基础币手续费影响实际数量，计价币手续费影响成本及卖出到账，沿用现有持仓成本计算。费前拆分使用同笔成交价格表达已知基础币费用的影响，不获取额外汇率。

缺少建仓、逐笔明细、真实成交时间或手续费时保留已知事实，并显示缺项。其他币种费用没有可靠换算依据时保留原币种，净盈亏为未知。模拟旧记录没有保存手续费时仍显示已知费前盈亏。订单创建、激活时间不当作成交时间，当前余额为零不证明某条历史何时清仓。没有时间的旧汇总单独保留为待核实片段；同方向的完整过程若受这些无法定位的变化影响，也不声称净盈亏已完整核验。

全历史仅指本地可查询且已归属的记录，不代表交易所开户以来全部历史。实盘按当前账户身份筛选，模拟按任务隔离。现货沿用任务专属成交/订单与成本基准，以及已有配置保护规则；已有历史不能通过普通配置变更重新归属为另一账户。共享账户中无法分清的仓位变化标记待核实，不混入其他任务的收益。读取页面不会下单、重新认领库存或补查历史。

## 现货统计

| 区域 | 时间口径与计算 |
| --- | --- |
| 累计投入 | 全部本地历史中的实际成交买入金额，不含手续费，不含人工成本校准；标的占比为该标的金额除以全任务金额 |
| 当前持仓 | 当前数量、剩余成本、加权平均成本、市值、浮动盈亏和持仓收益率；独立加载，使用账户/行情模块自己的更新时间 |
| 成交与已实现盈亏 | 最近 7 天或全部历史，按真实逐笔成交计数，并分买入、卖出；卖出时扣除对应持仓成本及手续费 |

同一订单分三笔成交计三笔，重复同步同一成交不重复计数。只有订单累计证据的旧记录可以支持已知投入金额，但不伪装成一笔真实成交，计数旁注明“已记录，明细不完整”。没有准确时间的记录不猜入最近 7 天。

最近 7 天卖出时会读取此前的建仓及成本，不截掉期初成本。买入手续费随卖出份额分摊，不在买入时和卖出时重复扣除。已清仓标的继续展示累计投入、成交与收益；无持仓时平均成本和持仓收益率显示 `—`。零投入占比为未知；某标的买入金额未知时不以零代替重算组合占比。

当前持仓市值和浮盈由已有账户接口加载，本地成交统计不等待实时行情。没有价格时仅相关估值未知。现货已实现收益与持仓历史共用加权成本步骤；人工校准可改变此后的持仓成本，不改写之前已确认的卖出盈亏。

## 接口与兼容

- `GET /api/history/positions?config_id=...&symbol=...&status=open|closed|unconfirmed&page=1&per_page=20`：已登录用户读取持仓摘要。响应包含 `items`、`total`、`symbols`、`as_of`、`complete`、`errors`。
- `GET /api/history/positions/{position_id}?config_id=...`：读取指定任务范围内的完整变化，其他任务的编号不能读取。
- `GET /api/stats/task-history/{config_id}`：在现货任务的 `statistics.spot` 中提供累计投入、`by_symbol`、`seven_days`、`all_history`、完整性及费用说明。旧字段含义不变。旧订单级摘要因证据不足不可计算时，旧期间字段为 `null` 并提供 `legacy_statistics_error`，新的逐标的结果仍明确呈现可用信息。
- `/api/history/position-cycles` 保留原兼容行为。模型上下文中的原统计不被新的逐笔计数替换。

新接口在同一个只读数据库快照中读取原始记录，先还原完整过程，再筛选与分页。不新增数据库表，不改写交易记录，不新增同步或后台任务。

```powershell
uv run --with playwright python tests/browser_position_workbench.py
```
