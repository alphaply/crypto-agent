# Agent 收益与市场多空指标

收益上下文由短期记忆 Agent 在每轮报告后的更新任务或手动整理时读取。适用于 REAL / STRATEGY；SPOT_DCA 不套用合约权益收益算法。交易每轮结束由配置的摘要模型按策略 Prompt 生成 `TradeReport v1`，保存行情解析、单一主策略、决策、未来 1h/4h 判断、风险、失效条件、观察点和摘要；执行事实由真实工具回执补充，原始分析另行保留。随后以本轮和前 4h 摘要、当前短期记忆及历史证据更新记忆。定时分析和绑定任务聊天读取完整记忆和最近三轮摘要，不逐轮追加完整收益快照和 7 天平仓账本。

默认决策上下文包括当前市场与账户、全局共享消息快照、任务长期规则、最新短期记忆和最近三轮策略摘要。各任务策略及记忆按 config_id 隔离，消息配置与摘要共享。最近三轮按时间顺序传入完整模型摘要，不重新展开原始分析。短期记忆注明覆盖区间和更新时间，输入与有效输出均不按字符数截断。服务商明确标记输出不完整时保留旧记忆；报告格式失败保留原分析与回执并显示无效状态。`{trading_rules_text}`、`{short_memory_text}` 和 `{recent_summaries_text}` 缺失时自动补充，已使用的区块不重复注入。Daily memory 生成路径已删除，`{history_text}` 渲染为空，旧 Daily Memory 章节和仅含该占位符的标题区块一并清理。市场数据失败不会顺带清空本地上下文。

自动规则维护已暂停，短期记忆模型不提供 `manage_trading_rules`，正常一次调用只更新动态 memory。既有长期规则保留，交易 Agent 与绑定任务聊天只读；人工仍可在后台锁定、修改、停用并查看版本。规则与摘录不能覆盖当前账户事实；开仓计划、挂单确认和真实成交分别表达。完整操作语义见 [交易流程](TRADING_WORKFLOW.md)。

- 起点收益率 =（最新有效快照权益 / 最早有效正权益 - 1）× 100%。严格按 config_id + symbol 过滤，不回退其他配置。缺少两个有效快照时标记 N/A；不会硬编码用户报告的 -8%。
- 当前回撤和最大回撤从同一历史快照序列计算，回撤显示为正数。包含最新快照时间和样本数；不使用实时可用余额替代权益，不冒充实时指标。
- 收益基准是保留历史的首个有效快照，不一定是任务启用日期，也不一定等于看板所选窗口起点。未调整出入金、划转及共享账户其他策略影响；快照会漏掉盘中回撤。现有实盘快照口径仍是钱包余额加所记录品种浮盈亏，不能当作严格独立策略净值。
- 同时提供现有本地账本最近 7 天完整平仓周期、胜率、盈亏比、平均盈亏和手续费前盈亏，保留未知和同步覆盖说明。没有完整周期不等于没有交易。

原始历史证据完整保存在短期记忆的 `position_summary` 中，供页面展开查看；模型决策只使用 `market_summary`。记忆 Agent 读取完整旧记忆、本轮及前 4h 摘要、历史证据与当前规则，保留统计截至时间、收益/回撤、样本数、手续费口径和主要教训。窗口包含本轮一次，同任务通过持久队列和锁按顺序处理；记忆失败只重试记忆，不重新交易。最近七天已读取的成交、完整周期及执行观察保持完整；交易所读取保留同步范围、分页预算与完整性说明，不能把已读取记录冒充账户全部历史。旧整点四小时批处理不再自动调度。模型失败或输出无效保留旧记忆；规则工具成功而最终记忆失败时独立记录 `partial`、错误和真实回执并停止自动重试，不把规则成功等同于整轮成功。

历史胜率与盈亏比只描述给定样本，不是下一笔交易的概率或正期望证明。复盘区分入场判断、风险规模和执行问题，无充分新证据时保留已有规则或标明证据不足，不能用“反向必赚”等事后推断更新长期规则。

后台「Agent 运行」需要登录，涵盖交易决策、报告整理（`strategy_summary`）、记忆复盘、聊天、聊天压缩、Jev 消息评分及生成式消息摘要。原始详情每任务保留最近 100 次、最长 30 天，累计用量独立持久保存。调用前保存实际渠道和费率，结束时优先使用服务商返回费用，否则根据输入、输出及缓存 token 估算，不重复累加推理 token。缺价或缺用量保持未知，各币种分别汇总，改价不回算旧调用。models.dev 按渠道和模型映射默认每 6h 同步，目录缓存 1h；手动价格优先，未匹配或失败保留现价。旧用量只迁移一次并标记历史估算。详见 [Prompt 设计](PROMPT_DESIGN.md)。

全局看板的权益对比按任务各自标的读取，再按 REAL、STRATEGY 和 SPOT_DCA 分组。REAL 的相同交易所、市场类型和 API key 账户只展示一条最新账户曲线，避免将共享账户重复相加；STRATEGY 使用任务自己的模拟权益；SPOT_DCA 显示所选资产累计投入。累计投入不等于净值，不跨模式混算收益。

交易接口的参数、方向、改单和执行确认规则随工具描述提供，不再重复拼接“本轮交易工具接口”。上下文明确当前 `exit_mode`；附带 TP/SL 合并进挂单行，独立模式保留按数量管理退出的语义。按配置、品种和持仓方向匹配；单向模式仅在本地订单 ID 对应时补充方向信息。交易所快照保留订单 ID、方向、价格和数量，本地计划状态、核验时间、异常及待确认改单只附加一次。保护价格与快照一致时不重复列目标；不一致或快照未见的本地保护记录明确标记待核对。`ACTIVE` 只表示最近一次核验通过，不保证当前交易所状态。

## 行情上下文

- 1h 运行档默认分析 1h/4h/1d：分别展示最近 24/12/7 根已收盘 K 线；其他普通档保留每周期最多 10 根。按时间升序列出 UTC 开盘时间、OHLC 和成交量；成交量使用交易所 OHLCV 原始单位。
- 显示窗口与计算历史分开：小时档和现货档抓取 600 根，其他普通档通常 1000 根、月线最多 60 根。EMA、Wilder RSI/ATR/ADX 等使用完整有效历史，并保留预热不足、过期、异常数据和时间缺口提示。
- 提供价格距 EMA20、EMA20 与 EMA50 价差的 ATR 倍数、EMA20 三根变化、RSI 三根变化、MACD 柱及其变化的 ATR 倍数、ATR 占价格百分比、前 20 根区间和相对成交量。此前区间与量能基准均排除最后一根，避免当前柱稀释比较基准。
- 1/3/15 根收盘变化描述历史动量，不代表预测收益。移除未配对价格和 RSI 极值的简化“背离”提示；同源指标也不视作多份独立证据。
- 缺失值显示 `N/A`，零成交量窗口不伪造 VWAP 或成交量分布；微小价格保留有效精度。指标参考价是最后收盘价，实时成交价可能不同。

新增指标在同一份完整已收盘历史上计算，通过 `decision_context.regime` 同时提供给定时分析和聊天：

- CHOP14：`100 × log10(sum(TR,14)/(HH14-LL14))/log10(14)`；提供数值、三根变化和当前状态的连续根数。38.2/61.8 仅作为描述性区间，无涨跌方向或胜率含义；零价格区间为 N/A。
- CMF20：20 根成交量加权的收盘区间位置；提供数值、三根变化及连续同号根数。它是 OHLCV 压力代理，不是真实资金净流入；高低价相等的 K 线贡献为零，窗口总成交量为零时为 N/A。
- Squeeze 状态：BB 使用 SMA20 ± 2 倍总体标准差；KC 使用 SMA20 ± 1.5 × SMA(TR,20)。这是明确参数的 BB/KC 收缩检测，不复刻另一套动量柱。两条 BB 均在 KC 内为 on，均在外为 off，其余为 neutral。输出连续收缩根数，以及观察到 on→off 后的根数（0 为当根）；重新收缩或数据不足时清空释放计数，不能从 off 凭空推断此前发生释放。涨跌方向继续结合现有 MACD 等证据。

持续根数受已加载历史限制；展示窗口不限制指标预热或统计长度。新增指标用于补充事实，尚未证明能改善策略收益。

消息读取使用最近一次全局快照，默认每 1h 聚合、回看 24h。Jev Decisions 先按可编辑标准做相关度过滤，独立生成模型再汇总，所有任务和聊天共享结果；读取不会重复付费评分。失效或失败时保留上一快照并显示 stale，关闭消息管道不继续注入旧快照。消息相关度不等于价格方向或交易胜率。

计算参考：[TradingView CHOP](https://www.tradingview.com/support/solutions/43000501980-choppiness-index-chop/)、[TradingView CMF](https://www.tradingview.com/support/solutions/43000501974-chaikin-money-flow-cmf/)、[LazyBear Squeeze 思路](https://www.tradingview.com/script/nqQ1DT5a-Squeeze-Momentum-Indicator-LazyBear/)。

## 市场多空指标

Binance USD-M 市场多空指标包括全球账户多空比、大户持仓多空比、大户账户多空比、主动买卖量比。每个接口取最近两个 5m 样本；只在时间戳正好相差 5 分钟时计算相对变化 `(最新/前值-1)×100%`。单项失败不影响其他项；数据超过 15 分钟、非有限数或未来时间戳不能作为有效当前值。

账户人数、持仓和主动成交量是不同口径，不是未来胜率，也不是单独的追涨或逆势入场信号。收益上下文用于评估已有表现，不承诺提高胜率，不改变交易工具的仓位与执行校验。角色权限和运行记录随代码重启加载，应用初始化负责所需数据库结构更新。

接口口径参考：[Binance 官方 USD-M 接口实现](https://github.com/binance/binance-futures-connector-python/blob/main/binance/um_futures/market.py)。
