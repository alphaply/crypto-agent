# 工作台配置与运行流程

## 页面与升级兼容

Dashboard 展示全部任务的数据总览，包括启用任务数、24 小时运行结果、消息更新时间、今日已知模型费用、收益与任务列表。独立的「Agents」页（`/agents`，管理入口 `/console/agents`）展示任务运行状态、K 线、持仓、固定报告和短期记忆；只加载当前选中任务的工作区。现货组合可切换标的和周期，移动端使用同一套选择器。旧 Dashboard 的 `symbol` 过滤及任务深链继续保留兼容。

新建聊天任务及单标的交易任务使用交易所市场目录：先选账户和现货/合约市场，再按币种、完整交易对或计价币搜索，支持分页。切换账户或市场会重新核验选择，不能继续使用上一个市场的无效标的。现货组合仍可多选。

配置页按任务与调度、消息聚合、模型与价格、交易账户、MCP、短期记忆、提示词及系统数据组织。管理员登录后能查看、复制、修改明文凭据；数据库继续加密保存。管理配置响应使用 `Cache-Control: no-store`。公开页面、普通消息接口和 MCP 工具不提供密钥。

升级保留已有运行间隔、自定义时段、显式行情周期、杠杆和交易记录。新建合约任务默认 60 分钟与 `hourly` 行情预设；内部 Agent 没有新增杠杆上限。MCP 的默认 5x 限制仅作用于外部 MCP 交易配置。

## 聊天标题与任务删除

聊天自动压缩较早上下文后，会根据会话内容总结标题；「当前会话记忆 → 整理」手动压缩成功时也会触发。同一批已压缩内容只尝试一次，没有新增可压缩内容时不重复调用。命名沿用当前会话的模型、兼容模式和 reasoning 配置，只采用完整最终回答；仅返回推理、回答截断或请求失败时保留原名。更新后的标题直接显示在会话列表与聊天顶部。

删除交易任务：进入「配置 → 任务与调度」，找到任务并点击「删除」，或使用任务编辑抽屉右上角的删除按钮，确认后删除配置及本地关联运行、历史数据。有现货持仓、挂单或待核验记录也可以通过这个专用删除入口删除，无需先改账户或模式。删除不会替你卖出现货、平仓或撤销交易所委托，删除后该任务也不再维护这些持仓与委托；需要处理时请在交易所操作。只想暂停任务可关闭启用开关。

仍有现货记录时，修改交易账户/模式、缩减持仓标的以及通过整份配置保存或导入间接移除任务继续受到保护；需要删除时使用上面的明确删除入口。

## 配置共享消息

1. 在「模型与价格」新增 Jev 渠道。选择 **TypeSafe · Jev 官方**，填写 TypeSafe API Key，默认 Base 为 `https://api.typesafe.ai/v1`、模型为 `jev-latest`，调用 `POST /v1/systemone`（[官方接口文档](https://api.typesafe.ai/docs)）。B.AI 用户选择 **BAI · Jev**，保留 `https://api.b.ai/v1`、`jev-1.13.0` 和 `POST /v1/decisions`。两者凭据独立；已有 B.AI 配置不自动切换。先保存渠道，再点击「获取模型列表」查询账户可用模型，也可手动填写模型名称。Jev 只能用于结构化评分。
2. 另配一个生成式模型作为摘要渠道。
3. 在「消息聚合」选择评分及摘要渠道，配置刷新间隔、来源、评分指令、五档标准与阈值。默认每小时更新、最近 24 小时、0–100 分阈值 60。
4. 在「消息聚合 → 律动 BlockBeats API Key」填写独立律动密钥，可从[律动官方 API 文档](https://www.theblockbeats.info/apiDoc)申请。服务以 `api-key` 请求头调用 `https://api-pro.theblockbeats.info/v1/newsflash`，按页获取 JSON 快讯，不使用律动 RSS。密钥加密保存，可以修改或清除；旧默认律动 RSS 来源自动迁移为 API，保留原名称、语言和启用状态。缺少密钥显示待配置；请求失败会标记来源异常并在可用时使用历史缓存，不会退回 RSS。原有宏观与加密来源、Polymarket 保留。
5. 币安公告使用官方签名 WebSocket 持续收集，需选择已保存 Binance 凭据；缺少凭据显示待配置。
6. 等待自动保存完成后点击「立即刷新」。处理监控显示采集、评分、过滤、摘要、发布各阶段，当前阶段进度、耗时、成功/失败/缓存/入选数量、相关度分布和各来源结果。运行时约每 2 秒更新，空闲时约每 10 秒更新；查看页面不会重新评分。

流程固定为采集 → 清洗去重 → Jev 评分 → 阈值过滤 → 普通模型摘要 → 原子发布快照。评分缓存包含内容、模型版本与评分规则，保留原始响应和置信度。摘要突出本轮新增消息。即使交易调度关闭或无启用 Agent，全局聚合仍由运行中的调度器维护；部署为独立调度进程时必须保留该进程。

部分来源失败发布降级快照并列出缺失来源；评分全部失败或摘要失败保留上份成功快照并标记过期。Agent、Chat、Dashboard 和 MCP 只读取已完成快照，不在页面或任务切换时重新评分。

条目明细可按失败、入选等状态筛选并搜索标题，查看每条实际模型请求、响应及错误。评分按返回概率的加权期望校验，并考虑响应数字的小数精度；超出可解释舍入区间的响应继续拒绝，记录原始分数、加权分数及允许区间，便于定位服务商返回不一致的问题。网络或服务端临时错误有限重试，结构错误不会无限重试。

开启全局 LangSmith 追踪并配置密钥与项目后，每次聚合记录父运行及采集、单条评分、摘要子运行，管理员可从监控页打开追踪。追踪不可用不影响正常评分与发布。内部追踪链接及调用 ID 不进入公开消息快照。处理历史保留最近 20 轮；新闻模型调用保留最多 12,100 条、最长 30 天，普通 Agent 仍为每任务最近 100 次、最长 30 天。进程中断后会将过期运行标记为中断，避免一直显示处理中。

相关接口：`GET /api/news`（安全快照）；管理员接口包括 `GET /api/news/status`、`POST /api/news/refresh`、`GET /api/news/sources`、`GET /api/news/runs`、`GET /api/news/runs/{run_id}` 和 `GET /api/news/scorer-models?provider_id=...`。

## 固定报告和记忆

每轮收尾阶段生成 `TradeReport v1`，记录 `config_id` 和 `run_id`，包含行情解析、单一主策略、交易决策、实际执行回执、未来 1h/4h 条件预测、风险与失效条件、下次观察点及摘要。观望与等待是有效决策。

渠道配置可选 `json_schema`、`tool` 或默认 `json`。是否能强制报告工具由渠道能力决定，与模型是否带 reasoning 无关。JSON 格式错误最多纠正一次；报告工具只提交报告，不能交易，格式修复也不重新执行交易。实际执行结果由原始工具回执附加，报告不得自行声称成交。无效报告保留原分析并明确标记。

摘要和记忆更新任务一起持久化。短期记忆按 `config_id + run_id` 去重，同一 Agent 顺序处理：本轮摘要 + 同 Agent 之前 4 小时摘要 + 当前短期记忆；当前摘要只计一次。保留窗口、来源摘要、版本与真实成交证据。失败保持旧记忆，后台重试仅处理记忆。短期记忆模型可继续审阅未锁定交易规则；纯分析聊天不能写交易 Agent 记忆。

Daily memory 以及旧固定四小时批次已停用，历史数据保留归档。现有日报生成 HTTP 接口返回 410。

## 现货时间与额度

```json
{
  "mode": "SPOT_DCA",
  "symbols": ["BTC/USDT", "ETH/USDT"],
  "dca_amount": 100,
  "dca_budget": 3000,
  "dca_schedule": {
    "frequency": "daily",
    "days": [0],
    "times": ["09:00", "21:00"],
    "timezone": "Asia/Shanghai"
  }
}
```

每周一 09:00 使用 `frequency: weekly, days: [0], times: ["09:00"]`。服务端与后台预览共同使用同一规则；`POST /api/config/schedule-preview` 返回接下来三次执行时间。

每个时槽产生一份组合额度，100 USDT 指所有标的的总额。成交、挂单占用与未知结果的预留都计入预算；撤单确认仅释放未成交部分。同一时槽的重试、多个工具调用、审批恢复和服务重启不创建新额度。下一时槽产生新额度，累计买入仍受总预算限制。观望也标记本时槽已运行；停机恢复仅补当前日或周内最近一个遗漏时槽。旧单时点字段继续兼容。

## 价格与用量

每个本地渠道独立选择人工价格或 models.dev 映射，显式填写目录服务商和模型 ID。同名模型不会跨渠道覆盖。输入、输出、缓存读取和缓存写入按每百万 token 计价，留空表示未定价，显式 0 才表示免费。

目录默认每 6 小时同步，也可使用 `POST /api/pricing/sync` 手动同步；`GET /api/pricing/sync/status` 显示结果，`GET /api/pricing/catalog?q=...` 搜索目录。目录共享缓存，失败保留旧费率。修改映射后先保存再同步；人工覆盖优先于自动价。

调用开始时保存渠道、模型、用途、任务与价格快照，结束时记录用量和费用。支持交易分析、聊天、运行摘要、记忆、Jev 评分及消息摘要；已有历史无法可靠归属的用量标为未知渠道。用量记录独立于可清理的输入输出日志，修改费率不会重算历史。缺少价格或 token 时明确显示未知，不按免费处理；不同币种分开统计。
