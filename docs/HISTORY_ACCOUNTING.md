# 周期盈亏与异常记录

实盘周期接口 `/api/history/position-cycles` 保留 `realized_pnl` 为手续费前盈亏，新增 `net_realized_pnl` 和 `fees_complete`。净盈亏从周期内全部入场和退出成交扣除一次手续费；费用缺失或费用币种不同于结算币时返回 null，不估算兑换，不包含账户资金费。已有本地周期读取时即可计算，无需覆盖历史原始金额。

`activity` 返回结构化成交统计，前端显示有限小数、覆盖状态、缺失数量，并折叠同步区间和未闭合周期。最近一次同步成功不代表滚动七天窗口完全覆盖；未闭合周期不是实时持仓。

空流、无正文且无工具调用、无效工具调用均作为失败处理。长度截断时，若全部工具调用的原始 JSON 完整、调用 ID/名称与解析结果一致，则保留调用进入正常工具校验和执行，后续模型结合工具结果继续回答；截断警告与原文一起保存。原始 JSON 不完整时不接受 LangChain 自动补齐的参数，也不执行同批次中其他调用。仅有截断正文仍按失败处理。错误直接保存历史，不再调用总结模型或写入策略记忆；失败向调度器传播，避免误标成功。截图中的空输出不足以单独判定网络断连，错误记录保留上游结束原因。

可恢复的断连、超时、限流、空响应和无效工具调用沿用全局 `llm_max_retries`，默认重试 2 次（总计 3 次请求），等待 1 秒、2 秒；更多重试时等待上限为 4 秒。Dashboard 进度显示当前请求次数。仅重试当前模型调用，不重跑交易工具或整轮任务，失败请求的部分工具计划会丢弃。输出额度耗尽、内容过滤和鉴权错误不重复发送相同请求；耗尽重试后保存失败记录。
