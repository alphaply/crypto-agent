# Proposal

## Why

跨标签页登录后，前台记忆编辑按钮读取最新浏览器凭证，但 API 使用旧凭证；保存被拒绝且错误不可见。事件的 UTC 时间也可能在新闻摘要、分析和记忆压缩时丢失时区，导致把 12:30 UTC 误认为北京时间 12:30。

## What Changes

- 同步跨标签页登录状态，保存请求使用最新凭证。
- 保存成功及时显示已保存正文；失败显示原因并保留编辑内容，沿用既有接口及权限。
- 保留来源时间及时区，提供完整可读时间和一致的模型时间规则；不猜测缺失时区，不批量重写历史。
- 时间规则版本参与新闻摘要缓存，完成回归与发布检查后推送 beta 和 Docker 两个标签，由用户更新服务器。

## Capabilities

### New Capabilities
- `event-time-context`: 新闻及模型上下文保留事件日期、时区和时间用途。

### Modified Capabilities
- `decision-state-context`: 已登录用户可靠编辑短期记忆，页面和后续模型读取相同的已保存正文。

## Impact

影响 React 登录状态、API 请求、记忆编辑及新闻/分析/摘要上下文。记忆写入接口保持兼容；新闻只增加时间说明字段，不修改原始时间值。无数据库迁移，不新增新闻来源或交易行为。
