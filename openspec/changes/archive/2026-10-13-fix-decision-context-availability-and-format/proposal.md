# Proposal

## Why

当前独立退出模式将正在整理或失败的策略来源替换为“整理中/暂不可用”，最近三轮摘要没有已发布版本回退，执行引用读取失败还可能隐藏整份策略背景。持仓和订单直接输出内部 JSON，重复快照字段和空值增加 token 开销并降低可读性。

## What Changes

- 将已发布策略内容与整理任务状态分开：候选校验完成后原子发布；排队、失败、重试和新来源到达期间继续提供同范围有效内容。
- 短期记忆与近期摘要分别读取、分别降级；展示最近三条已发布策略摘要及真实来源时间，不把较旧内容称作最新三轮。
- 执行引用独立解析，最新核验仍可解除旧限制，证据读取失败不清空策略正文；不回退到含旧执行禁令的混合原文。
- 保留原文、来源身份和手工修改/删除的失效语义。已有有效视图升级后立即可读，无有效视图的旧数据通过既有后台整理补齐；已失败转换支持有界的升级修复和管理端重试，状态与错误留在管理接口/页面。
- 按确认的文本/表格格式渲染持仓与挂单，保留完整订单 ID、方向、用途、数量、限价/触发价和状态。观察时间集中展示，覆盖缺口与实际异常单列，不展开无关内部 JSON。
- 定时决策和绑定任务聊天使用相同渲染；补充并发、故障隔离、身份与精度、提示词体积回归。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `decision-state-context`: 增加已发布策略持续可用及紧凑状态展示要求，修订迁移期间的占位符行为和近期摘要时效语义。

## Impact

- `backend/agent/context_projections.py`、`decision_context.py`、记忆持久化/整理链路及管理状态接口；必要的增量 SQLite 元数据迁移。
- `backend/utils/trade_context.py` 的纯渲染层、相关 Prompt 标题及绑定聊天集成；不改变执行核验、订单操作或交易授权。
- 记忆管理状态提示、针对性离线测试与 README / Prompt / 交易流程文档。
- 不涉及另一项已完成的供应商模型发现变更，不自动归档、发布或操作真实交易账户。
