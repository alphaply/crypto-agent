# Implementation handoff

## 范围与状态

已按用户修订后的方案开发：短期记忆纯文本、旧版 7 天成交/平仓记录、Paper 独立 tab、交易工具简洁结果及提交后核验退出工具调用。开发与验收分别记录在 tasks.md，最终版本的测试和验证由用户接管。

此前开发阶段执行过部分后端检查、前端构建和浏览器检查，随后代码仍有修改，也有中断或未完成的检查。这些记录不构成最终版本全部通过的证明。用户接管后未追加测试、浏览器验收、实盘验证或 OpenSpec 严格校验；Docker 构建属于用户另行授权的交付步骤。

## 已开发行为

- Agent 完成决策及工具执行后保存本轮有效策略压缩，再入队短期记忆更新。自动和手动整理共用最近 4h 全部有效压缩摘要、旧版 7 天成交/平仓记录和上一轮有效记忆，本轮摘要只计一次。独立新闻、最新回执附加段及全历史权益统计不进入该素材链。
- 记忆模型返回一份完整纯文本，不再回传 JSON、来源哈希或多份投影，也不进行“纯策略”正则拒绝或格式/内容纠正。非空、完整响应、无工具调用检查，以及传输重试、费用审计、租约和失败保留旧记忆仍保留。
- 新文本直接发布；来源范围、内容哈希和执行关联由程序保存。旧投影生产、纠正及旧契约恢复重排退役，历史表、原文和有效已发布内容保留。兼容重试接口只重排仍有源摘要的失败记忆任务。
- 金融工具按请求顺序执行，依据交易所接口响应返回；本项提交后不追加订单/持仓查询、轮询、sleep 或超时补查。必要前置检查及后台按原身份核验继续保留。受理成功只表示提交成功；网络超时内部仍为未知，不能自动重发。
- 执行、管理发现和后台恢复统一账户锁顺序，保留数据库版本比较；确认未提交的版本冲突重读状态并重新准入。已取得交易所 ACK 后的本地持久化失败保留已受理结果，不改写成确定未提交。新旧 MCP 相同 ID 重放读取本地证据，不重新提交或补查交易所。
- unknown/pending 停止本批后续项，保留已完成及未执行事实。显式 independent 在明确失败时保留原依赖策略，后台不补发尾项。模型展示逐项文本，内部停止判断、审计及 MCP structuredContent 保持结构化事实。
- 归属索引已完成订单归属发布、只剩历史周期统计重建时，允许继续当前成交同步；缺必要证据、真实归属冲突、权限或数量不符仍拒绝。`Ownership evidence indexing incomplete` 表示本地同步未完成、保护动作未提交，不等于交易所拒绝。
- Paper 面板移至管理页独立 **QQBot · Paper** tab，共用原设置、账户接口和 Key 管理能力。
